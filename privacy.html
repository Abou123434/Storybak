Politique de confidentialité

Dernière mise à jour : 18 septembre 2026

Cette politique de confidentialité décrit comment Storybak (« le Jeu », « nous ») traite les informations des utilisateurs qui jouent au jeu, disponible sur le web et sur mobile.

1. Données collectées

Storybak est un jeu de mémoire simple. Nous ne collectons aucune information personnelle identifiable (nom, e-mail, numéro de téléphone) pour faire fonctionner le jeu.

Selon la version utilisée, les données suivantes peuvent être traitées automatiquement :

  • Statistiques de jeu (scores, progression), stockées localement sur l'appareil
  • Données techniques générales (type d'appareil, système d'exploitation) à des fins de bon fonctionnement de l'application

2. Publicités

Si des publicités sont affichées dans le Jeu, celles-ci peuvent être fournies par des régies publicitaires tierces qui utilisent leurs propres technologies de suivi, conformément à leurs propres politiques de confidentialité.

3. Partage des données

Nous ne vendons pas les données des utilisateurs. Aucune donnée personnelle n'est partagée avec des tiers, en dehors des partenaires techniques nécessaires au fonctionnement du Jeu (ex. hébergement, régies publicitaires le cas échéant).

4. Sécurité

Nous prenons des mesures raisonnables pour protéger les informations traitées dans le cadre du Jeu contre tout accès non autorisé.

5. Utilisateurs mineurs

Storybak ne collecte pas sciemment de données personnelles auprès d'enfants. Si vous pensez qu'un enfant nous a fourni des informations personnelles, contactez-nous afin que nous puissions les supprimer.

6. Modifications de cette politique

Cette politique peut être mise à jour occasionnellement. Toute modification sera publiée sur cette page avec une nouvelle date de mise à jour.

7. Contact

Pour toute question concernant cette politique de confidentialité, vous pouvez nous contacter via la page du Jeu.
